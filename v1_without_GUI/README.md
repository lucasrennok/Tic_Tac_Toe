# :green_book: Tic Tac Toe — Terminal

Jogo da velha para rodar no terminal, sem dependências (só Python 3.10+).

## Modos

- **1 jogador** contra o computador, que usa o algoritmo **minimax** e por isso
  nunca perde (no máximo empata).
- **2 jogadores** no mesmo computador.

## Como jogar

```sh
python main.py
```

O tabuleiro mostra os números de 1 a 9 nas casas livres; é só digitar o número
da casa onde quer jogar:

```
 1 | 2 | 3
-----------
 4 | 5 | 6
-----------
 7 | 8 | 9
```

Você é o **X** e o computador é o **O**.
